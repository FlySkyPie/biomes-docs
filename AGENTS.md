# Biomes Docs — Agent Guide

## Project Overview

This is a **Docusaurus 2.4.1** documentation site for the [Biomes](https://github.com/ill-inc/biomes-game) open-source sandbox MMORPG. It is deployed to GitHub Pages at `https://ill-inc.github.io/biomes-docs/`.

The **source Biomes game repository** is at `ill-inc/biomes-game` (not this repo). This repo is purely the static documentation website — extracted docs live under `docs/`.

## Essential Commands

| Command | What it does |
|---|---|
| `pnpm start` | Dev server on `localhost:8080` with HMR |
| `pnpm build` | Static build to `build/` directory |
| `pnpm typecheck` | TypeScript type-check via `tsc` |
| `pnpm deploy` | Build + push to `gh-pages` branch (needs `GIT_USER`) |
| `pnpm clear` | Clear Docusaurus cache |

CI uses **pnpm 10.9.0** and **Node 20**. The `pnpm` lockfile (`pnpm-lock.yaml`) is required — use `pnpm install --frozen-lockfile` in CI.

## Key Conventions

- **Sidebar is autogenerated** (`sidebars.js` uses `autogenerated`). File/folder ordering is controlled by `sidebar_position` frontmatter in each doc (defaults to lexical order otherwise).
- **Use `_category_.json`** files in doc subdirectories for category labels and metadata.
- **Images in Markdown**: reference via `/img/<file-name>`.
- **Images in React components**: import via `require("@site/static/img/<file-name>").default`.
- **ReactPlayer** is available for YouTube embeds (used in `intro.mdx`).
- **Broken links throw errors** during build (`onBrokenLinks: "throw"`) — always run a build before pushing.
- **Tailwind CSS** is not active — its config is an empty shim for Docusaurus compatibility. All styling is via **Infima** CSS variables overridden in `src/css/custom.css`.
- **Only English locale** configured (`i18n` only has `"en"`).

## Deployment

- Triggered by pushes to `main` via `.github/workflows/deploy.yml`.
- Uses `peaceiris/actions-gh-pages` to publish `build/` to the `gh-pages` branch.
- Base URL is `/biomes-docs/` — all internal links must be relative to this.

## Doc Content Patterns

- Docs describe the **Biomes game source code** at `ill-inc/biomes-game`. Most pages link directly to GitHub source paths (e.g., `https://github.com/ill-inc/biomes-game/tree/main/src/server/web`).
- **Server architecture** (docs/basics/server-overview.md): 10+ microservices (web, logic, asset, trigger, chat, task, sync, oob, newton, anima, map, replica, gaia). All communicate through ECS component updates synced via the `sync` server.
- **ECS** (docs/basics/ecs.md): Entity Component System is the core paradigm — game state and interactions are ECS events.
- **Bikkie** (docs/basics/bikkie.md): Biomes' bespoke game data/asset definition system.

## Gotchas & Non-Obvious

- **CLI shows `pnpm start` but `package.json` uses port 8080**, not the Docusaurus default 3000. This matters if you see port conflicts.
- **Node >=16.14 required** (engines field), but CI actually uses Node 20.
- **README says `pnpm start` but the Biomes main repo uses `yarn`** — do not confuse them. This docs site is pnpm-only.
- **`pnpm-lock.yaml` is committed** and CI uses `--frozen-lockfile`. Any dependency change requires updating the lockfile and committing it.
- **The Biomes game repo has its own docs/ folder** (at root) — this repo is a separate extracted copy for public documentation. Edits here do NOT flow back to the game repo.
- **No tests** exist in this repo (no test runner, no test files). `pnpm build` is the main validation.
- **Contributions must follow** the Generative Code Contribution Policy in `CONTRIBUTING.md` — LLM-generated content must be recorded with specific commit author format: `{Tool} {Version} <{Model}@{Provider}>`.
